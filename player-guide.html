Belt Scroll Action

STREET BREAKER

スマホでもPCでも遊べる、横スクロールのドット絵アクションゲームです。iPhoneでは横向きで遊ぶと操作しやすくなります。

ゲームを開く

GitHub Pagesを使う場合の遊ぶリンクです。表示できないときは、GitHub側でPagesが有効になっているか確認してください。

まず知っておくこと

おすすめ環境

iPhoneはSafariで開き、画面を横向きにして遊ぶのがおすすめです。ホーム画面に追加すると、アプリのように起動できます。

音について

ブラウザの制限により、BGMやSEは画面をタップしてゲームを開始したあとに鳴り始めます。音量は端末側で調整してください。

ゲームの目的

敵を倒して右へ進み、ステージを突破します。ステージ1から5をクリアすると、最後のステージ6に挑戦できます。

ゲームの流れ

1. キャラと難易度を選ぶ

PETIMANまたはROOEEBEEを選び、Easy、Normal、Hardから難易度を選択します。

2. 敵を倒して進む

エリア内の敵を倒すと、右側へ進めるようになります。ドラム缶や木箱も壊せます。

3. GOが出たら右へ

右側にGO表示が出たら、画面右端へ移動します。次のエリアへ進みます。

4. 最後のボスを倒す

ステージ1から5をクリアするとステージ6が解放されます。大ボスを倒せばゲームクリアです。

PC操作

移動

矢印キー、またはWASDで移動します。

攻撃

Spaceキー、またはクリックで通常攻撃します。空中ではジャンプキックになります。

スキル

Qで必殺技、Rで超必殺技を出します。Shiftと左右入力でジャンプできます。

攻略のコツ

囲まれない

敵に挟まれると危険です。上下移動とジャンプで距離を取り、正面から一体ずつ倒しましょう。

障害物を利用する

ドラム缶や木箱は破壊できます。敵との距離を作る目印としても使えます。

ボスは焦らない

ボスは強い攻撃を持っています。攻撃後のすきに近づき、危ないときは必殺技で押し返しましょう。
