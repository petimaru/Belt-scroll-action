# Belt Scroll Action

ベルトスクロールアクションゲームのブラウザ試作です。

現在はフェーズ1からフェーズ2-1に進んだ段階で、スマホ横持ち操作の気持ちよさを確認しながら作っています。

## 現在できること

- iPhone横持ちでのプレイ
- 左操作エリアのドラッグ移動
- 右操作エリアのタップ攻撃
- 3連コンボ攻撃
- 3発目の高ダメージ攻撃とノックバック
- 右操作エリアの上スワイプジャンプ
- ジャンプ中タップのジャンプキック
- ジャンプ中の敵攻撃回避
- 敵タイプ1「ゆっくり近づく敵」
- 敵の攻撃予備動作と攻撃範囲
- 敵の被弾ヒットストップ
- 頭上のダメージ表示
- スコア表示
- バイク敵の乱入
- バイク敵の `CAUTION!` 予告
- バイク突進のジャンプ回避
- バイク敵の撃破

## 操作

スマホ:

- 左半分ドラッグ: 移動
- 右半分タップ: 攻撃
- 左半分で左右入力しながら右半分を上スワイプ: 左右ジャンプ
- ジャンプ中に右半分タップ: ジャンプキック

PC:

- `WASD` / 矢印キー: 移動
- `Space` / クリック: 攻撃
- `Shift + 左右`: ジャンプ
- 空中で `Space`: ジャンプキック

## 現在の仮仕様

今はテストプレイしやすくするため、敵出現はWave式です。

ただし最終形はWave式ではなく、ベルトスクロールアクションらしいエリア進行制にします。

将来の流れ:

```text
敵を全滅
右側へ進めるようになる
次のマップ / 次の画面範囲へ移動
次エリアの敵・ギミックが出現
```

今の `spawnWave()` は将来、`spawnAreaEnemies()` のようなエリア単位の敵出現処理へ置き換える想定です。
